# Checklist Breve de Pruebas y Entrega

## 1) Checklist de pruebas mínimas
- [ ] Ejecuté el caso principal y obtuve salida esperada.
- [ ] Probé al menos una entrada inválida.
- [ ] Registré resultados de pruebas en `docs/plan_de_pruebas.md`.

## 2) Checklist de documentación
- [ ] Completé `docs/propuesta.md`.
- [ ] Completé `docs/caso_de_uso.md`.
- [ ] Revisé coherencia con `README.md`.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` funciona en mi entorno.
- [ ] El archivo principal en `src/` coincide con mi lenguaje elegido.
- [ ] No usé frameworks ni dependencias complejas.

## 4) Checklist de entrega final
- [ ] El proyecto se mantiene pequeño y viable.
- [ ] El alcance y límites están claramente documentados.
- [ ] El repositorio está ordenado y con nombres claros.
- [ ] La propuesta está lista para revisión en GitHub Classroom.
