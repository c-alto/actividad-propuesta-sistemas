# Checklist Breve de Validación

## 1) Checklist de pruebas mínimas
- [ ] Ejecuté al menos 3 casos de prueba.
- [ ] Probé al menos 2 escenarios de error.
- [ ] Registré resultados esperados y obtenidos.

## 2) Checklist de documentación
- [ ] Completé `docs/propuesta.md`.
- [ ] Completé `docs/caso_de_uso.md`.
- [ ] Completé `docs/plan_de_pruebas.md`.
- [ ] Verifiqué consistencia entre alcance y caso de uso.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` corre sin fallas de sintaxis.
- [ ] Existe archivo principal en `src/`.
- [ ] El prototipo mínimo produce una salida verificable.

## 4) Checklist de entrega final
- [ ] Repositorio ordenado y sin archivos basura.
- [ ] Nombres de archivos claros y en minúsculas.
- [ ] Último commit describe claramente el avance.
- [ ] Todo el trabajo está en la rama correcta.
